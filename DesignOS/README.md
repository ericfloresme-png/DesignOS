# DesignOS

DesignOS será una plataforma para crear, desarrollar, probar, versionar, documentar y mantener sistemas computacionales orientados a arquitectura, siguiendo metodología SSD/SDD.

## Estado actual

El proyecto se encuentra en la fase de inicialización de su estructura base. En esta etapa no se han implementado interfaz ni funcionalidades finales; únicamente se han creado los espacios para especificaciones, código, sistemas, pruebas, evidencia, conocimiento y documentación.
